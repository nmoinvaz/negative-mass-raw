pr      #73 implicit: Taylor steps of N(x, y, y', y'') = 0 with the root branch carried by continuity (OPEN) by nmoinvaz  main <- feat/implicit-taylor-r2  https://github.com/nmoinvaz/multishoot/pull/73
        | Adds `multishoot::implicit`: Taylor steps of an implicit second-order ODE `N(x, y, y', y'') = sum_g A_g(x) y^a y'^b y''^c = 0`, a polynomial in y'' of any degree. The caller supplies the monomials and, at each step's start, the Taylor coefficients of every A_g (`Coefficients`, as `plane`'s `JetSource`); the module knows nothing of any one problem. It was built for a downstream crate (https://github.com/nmoinvaz/negative-mass/issues/190), whose #167, #183 and #184 checks run unchanged on it.
        | 
        | - `Recursion`: order k of N set to zero and solved for `y''_k`, which enters linearly with the factor `A0 = dN/dy''` at the order-0 values (one division per step); `y_k`, `y'_k` from `y'_(k-1)`, `y''_(k-1)`. Order 0 of N is not imposed, so N is constant along the flow. The step variable is `s = (x - x0)/l`, l a power of two, so coefficients do not overflow near a singularity. The Cauchy sums go through multidouble's dot accumulators (`Scalar::cauchy`, `field::cs` on a lane's field): plain sums of products lost a planted walk that the lane code kept (a cancellation, order k of N is a difference of near-equal convolutions).
        | - `Scalar`, `Real`: `f64`, `DD`, `QD`, `OD`, and `Fl<T, 1>` of any lane (duals and jets). Its own small trait, next to `plane::Real`: the two overlap and can be unified later.
        | - `Walker`, `WalkOpts`, `WalkOut`, `Branch`: steps by `taylor::step_from_norms` on the largest coefficient of orders kt - 1 and kt (each field relative to its |c_0|, or not), checkpoints, the landing rule, Horner's sum. The branch is chosen once, by the data, and carried; no root is picked by its order. `Project` makes one Newton correction of y'' at each step's start, `Conserve` none. `form`, `planned`, `advance` let a caller watch each step (a singularity locator, say).
        | - Where `dN/dy''` vanishes: `Stop::ZeroPivot` (no division by zero), `Stop::Pivot` when `|A0| <= pivot_abs` with an estimate of the zero, `x* = x - beta A0/A0'`, `beta = 1/(1 - A0 A0''/A0'^2)` (exact for a pure power, an estimate otherwise), and `WalkOut::crossings`: a sign change of A0 between two step starts is a double root that the branch passes, located by the zero of A0's series in the step.
        | - `taylor_shift`: the jet of a polynomial in x about x0 in the scalar's precision.
        | - `control::ImplicitControl` (feature `mutate`): `SkipOrder(k)`, `RecipDD`, `NoPivotCheck`, `NoCrossing`, `ExponentHalf`, `NoPivotStop`.
        | - README: a section for the module, with the property below.
        | 
        | **Which mode near a double root.** Use `Project`. `Conserve` keeps N at its start value, a rounding eps and not 0, and for N = eps a double root is two roots: the crossing becomes an avoided crossing, the Taylor series about a point at distance d has radius about d, the steps shrink toward it and the walk ends with `Stop::Tiny`. `Project` sets N = 0 at each step's start and crosses. Away from `A0 = 0` the two agree to roundoff.
        | 
        | **Planted checks** (`tests/implicit.rs`; the pass criteria are in the file's doc comment and were written before the first run). Lanes f64, dd, qd at order `Plan::optimal_kt(tol)` = 22, 42, 80 (tol 1e-14, 1e-30, 1e-62), bar 1e6 eps; closed forms (exp, cosh, cos, powers of (-x)) share no code with the recursion. Branches of N1 = y''^2 - (y + x y')^2 (quadratic), N3 = N1 (y'' - 2y) (cubic, three real roots) and N4 = N1 (y''^2 - 4y^2) (quartic): nine branches, from x = 0 to 3, each meeting other roots at double roots (x = 1, sqrt 3, a root of u tanh u = 1, y = 0). Two folds, `16 y''^2 + 4 y'^2 + 225 x + 25 x^3 = 0` (exponent 1/2) and `3 y' + 2 y''^3 = 0` (exponent 1), both ending at x = 0, and a start at an exact double root.
