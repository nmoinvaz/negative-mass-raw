Conventions read from the same paper (TeX source, NdimWH_130910rev2.tex):
  - n-dimensional spacetime: S = ∫ dⁿx √−g [...], metric ds² = −f e^{−2δ}dt² + f⁻¹dr² + R²h_ij dx^i dx^j, h the unit
    (n−2)-sphere (lines 269-306). So n = D.
  - throat radius R(0) = a; "we can assume a = 1 and f₀ = 1 without loss of generality" by t̃ = t/a, r̃ = r/a, R̃ = R/a
    (line 377, note_1). So ω² here is ω²a².
  - static solution f ≡ 1, R′ = √(1 − (a/R)^{2(n−3)}) (Eq. massless-sol-2), so r is proper distance and t the throat's
    proper time: the same coordinates as this repository's ds² = −dt² + dl² + r(l)² dΩ.
  - perturbations f₀+εf₁e^{iωt} etc. (lines 483-490), so a mode e^{Wt} has ω² = −W², and W²a² = −ω².
  - regularized master equation −Ψ₁″ + W(r)Ψ₁ = ω²Ψ₁ (3.17) with W(r) = −[3(n−2)²/R₀^{2(n−3)} − (n−4)(n−6)]/(4R₀²) (3.18).
    No numerical method, grid, domain or tolerance is stated for the eigenvalue search; the acknowledgments say "Numerical
    computations were carried out on SR16000 at YITP in Kyoto University, and on the RIKEN Integrated Cluster of Clusters".
